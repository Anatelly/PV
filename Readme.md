**В этом проекте пытаемся реалиовать имитационный стенд фотоэлектрической панели. Т.е. принимаем данные с датчика освещенности, датчика температуры -> преобразуем с помощью мат. модели эти данные в ток/напряжение -> генерируем напряжение через ЦАП.**

Для разработки используется плата от WeAct Studio. Подробная информация:
https://github.com/WeActStudio/MiniSTM32H7xx

В процессе была выявлена ошибка с работой через DMA контроллер. Ошибка решилась откючением D-кеша в файле линковщика. Статья:
https://community.st.com/t5/stm32-mcus/dma-is-not-working-on-stm32h7-devices/ta-p/49498
